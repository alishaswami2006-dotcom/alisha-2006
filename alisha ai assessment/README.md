# ✨ LUMÉA PARIS — Luxury Botanical Cosmetics & Skincare

A modern, responsive, and aesthetic e-commerce web application designed for a luxury cosmetic brand with interactive features, fluid animations, and high-conversion UX.

---

## 🌟 Quick Start (Instant Preview)

You can launch and browse the website immediately without installing anything:

1. **Option A (One-Click):**
   - Double-click `Open_Cosmetics_Store.bat` in this folder.
   - Or open [index.html](file:///c:/Users/SUNRISE%20COMPUTERS/alisha%20ai%20assessment/index.html) in any web browser (Chrome, Edge, Opera, Firefox).

2. **Option B (Vite / React Node.js Project):**
   - If Node.js is installed:
     ```bash
     npm install
     npm run dev
     ```

## 💎 Features & Capabilities

- **Editorial Luxury Design**:
  - High-end typography (`Playfair Display` serif headers + `Plus Jakarta Sans`).
  - Warm champagne gold, French rose gold, and deep velvet noir color palette.
  - Subtle frosted glassmorphism and gold shimmer accents.

- **Dynamic Product Catalog**:
  - 12 curated botanical products across **Skincare**, **Makeup**, **Fragrance**, and **Bath & Body**.
  - Interactive shade selector dots for lipsticks & foundations.
  - High-resolution imagery, volume indicators, and badges (*Bestseller*, *Clean Beauty*, *Award Winner*).

- **E-Commerce Functionality**:
  - **Live Currency Converter**: Switch between USD ($), EUR (€), GBP (£), and INR (₹).
  - **Real-Time Search & Category Filters**: Instant filtering by keywords and categories.
  - **Sort Options**: Filter by Featured, Price (Low to High / High to Low), and Rating.
  - **Slide-Over Shopping Bag**:
    - Item quantity controls (+ / -) & quick remove.
    - Free Express Delivery progress bar (unlocks at $50).
    - Promo Code validation (`GLOW20` for 20% off, `LUMEA10` for 10% off).
  - **Interactive Skin Consultation Quiz**: Diagnostic quiz recommending customized routine.
  - **Full Mock Checkout Flow**: Credit card / address inputs, real-time total, and confetti celebration order confirmation modal.
  - **Wishlist Drawer**: Save favorites with heart animations.
  - **Customer Testimonials & Verified Reviews**: Social proof showcase with 5-star ratings.
